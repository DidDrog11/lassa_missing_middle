# The Missing Middle: Clinical Phenotypes and Trial Endpoints in Lassa Fever

**Status:** In Development

## Project Overview

This repository contains the analytical pipeline for investigating the clinical phenotype distribution of hospitalised Lassa fever patients. Standard Phase 2/3 therapeutic trials (such as the SAFARI trial) are ethically bound to exclude severe clinical presentations. This project evaluates the epidemiological impact of these exclusion criteria on the statistical viability of using hospital-based endpoints for future prophylactic vaccine efficacy trials.

## Primary Objectives

1. **Phenotype Distribution:** Quantify the proportion of RT-PCR-confirmed Lassa fever cases presenting with mild, moderate, and severe disease across two tertiary referral centres in Edo and Ondo states (Aug 2021 – Oct 2022).
2. **Endpoint Power Modelling:** Simulate required sample sizes for Phase 3 vaccine trials relying on a 'hospitalised severe disease' endpoint, given the observed baseline incidence.
3. **Spatial Access Constraints:** Model the non-linear relationship between estimated geographic travel time to isolation wards and the probability of presenting with trial-exclusionary severe disease.

## Data Governance

To comply with the Nigerian Data Protection Regulation (NDPR) and institutional ethics protocols, **no raw or processed clinical data is hosted in this repository**. 

* The `data/` directory is strictly ignored via `.gitignore`.
* A synthetic, structurally identical dataset is provided in `data/metadata/synthetic_baseline.csv` to allow external researchers to verify the analytical pipeline and spatial models without accessing the restricted aggregate hospital registries.


```
safari-missing-middle/
├── data/
│   ├── raw/                  # (GIT IGNORED) Aggregate hospital registries
│   ├── processed/            # (GIT IGNORED) Cleaned datasets for modelling
│   └── metadata/             # Data dictionaries and variable definitions
├── scripts/
│   ├── 01_data_cleaning      # Standardisation of exclusion criteria 
│   ├── 02_clinical_epi       # Phenotype distribution and CFR calculations
│   ├── 03_power_sim          # Vaccine efficacy Monte Carlo simulations
│   └── 04_spatial_access     # Friction surface and travel-time modelling
├── docs/
│   ├── protocol/             # Study protocol and Penn State ethics application
│   └── manuscript/           # Drafts of the brief report
├── outputs/
│   ├── figures/              # Generated plots and spatial maps
│   └── tables/               # Summary statistics and model outputs
├── .gitignore                
├── LICENSE                   
└── README.md                 
```

## Reproducibility 

The analytical pipeline is sequentially numbered in the `scripts/` directory. All outputs (figures and tables) generated by the scripts are deposited in the `outputs/` folder and correspond directly to the figures in the drafted manuscript.
